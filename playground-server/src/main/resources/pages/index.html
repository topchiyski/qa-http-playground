qa-http-playground

A local HTTP API for practising curl, REST Assured, Selenium and Gatling — a target you own, so you can test and load-test it as hard as you like.

Local and lab networks only. This server deliberately echoes requests, sets arbitrary headers and redirects anywhere. Do not expose it to the internet.

Swagger UI OpenAPI JSON Try /get

Guides live in the repository's docs/ folder: per-endpoint pages, learning paths and a load-testing guide. Server metrics: http://<host>:8081/actuator/prometheus.

Request inspection

  • /anythingANYEchoes method, args, headers, body, form, files, JSON
  • /getGETEchoes query args and headers
  • /headersRequest headers
  • /ipClient IP (?format=text for plain text)
  • /user-agentUser-Agent header
  • /hostnameServer hostname
  • /dump/requestRaw HTTP/1.x request dump
  • /envHTTPBIN_ENV_* variables
  • /uuidRandom UUID v4
